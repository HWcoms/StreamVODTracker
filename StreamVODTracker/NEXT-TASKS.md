# 다음 작업 목록

다음 UI/데이터 작업은 아래 순서로 진행한다. 완료한 항목은 상태와 검증 결과를 이 문서에서 갱신한다.

## 1. 날짜 입력 달력

- 다시보기 직접 추가 팝업의 방송 날짜 입력란 오른쪽에 달력 아이콘 버튼을 둔다.
- 버튼을 누르면 날짜 선택 달력이 열리고, 선택한 날짜가 입력란에 반영된다.
- 직접 입력도 계속 허용하고 기존 날짜 검증을 유지한다.

## 2. URL과 파일 경로 동시 보관

- 영상 등록 팝업에서 URL 링크 입력 아래에 파일 링크/경로 입력을 표시한다.
- URL과 파일 경로는 한 영상 항목에 함께 저장될 수 있다.
- 파일이 지정되지 않았으면 파일 링크 행은 빈 상태로 둔다.
- 데이터 모델과 CSV 헤더를 함께 갱신하며 기존 CSV 데이터가 보존되도록 호환 처리를 추가한다.
- 카드에서 URL은 기본 브라우저로, 파일 경로는 연결된 앱으로 연다.

## 3. 보기 아이콘의 활성 상태 표시

- 썸네일 표시/숨김 버튼은 현재 상태가 아이콘으로 구분되어야 한다.
- 그리드/리스트 보기는 한쪽을 활성화하면 반대쪽을 비활성 상태로 표시한다.
- 비활성 아이콘 버튼의 배경은 투명하게 하고, 아이콘 정렬과 크기는 현재 버튼 크기에 맞춘다.

## 4. 검색 결과 정렬

- 검색창 오른쪽에 정렬 옵션을 배치하고 실제 정렬 기능을 연결한다.
- 제목, 방송 날짜 등 사용자가 이해하기 쉬운 기준을 제공한다.
- 정렬은 검색/선택 채널 결과에 적용하며 CSV 저장 순서나 기존 영상 데이터를 바꾸지 않는다.

## 5. 새로고침 결과 알림

- 새로고침 아이콘을 눌러 채널 영상 조회와 반영이 성공하면 `새로고침 완료` 알림을 표시한다.
- 조회 결과가 기존 목록과 같아 새로 반영할 내용이 없으면 `새로고침 할 내용 없음` 알림을 표시한다.
- 조회에 실패하면 성공 알림 대신 실패 알림을 표시하고 기존 목록을 유지한다.

## 6. 스트리밍 사이트별 채널 필터

- 왼쪽에서 치지직 또는 SOOP을 선택하면 채널 목록에 해당 사이트의 채널 카드만 표시한다.
- 전체 보관함 등 다른 항목을 선택했을 때의 채널 목록 동작은 기존 탐색 구조에 맞춰 유지한다.
- 사이트 선택을 바꿀 때 선택된 채널과 다시보기 목록도 일치하도록 갱신한다.
